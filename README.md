Hiro PetShop merupakan aplikasi petshop sederhana yang dirancang untuk memudahkan pengguna dalam melihat dan mencari berbagai kebutuhan hewan peliharaan. Aplikasi ini menyediakan fitur pencarian, kategori hewan seperti anjing, kucing, kelinci, dan burung, serta menampilkan produk-produk populer beserta harga dan deskripsinya. Tampilan aplikasi dibuat sederhana dan mudah digunakan dengan navigasi yang jelas.
